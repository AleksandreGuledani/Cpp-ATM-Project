# C++ ATM

A console-based ATM simulation developed in C++ to practice object-oriented programming, file handling, and implementing common banking operations.

## Features

* 💳 Card validation
* 🔐 PIN authentication
* 💰 Balance checking
* 💵 Deposits and withdrawals
* 🧾 Transaction history
* 🔑 PIN changes
* 💱 Basic currency conversion
* 📁 Persistent transaction records using file I/O

## Available Operations

The application simulates several common ATM operations:

* Validate a card using card information
* Authenticate users using a PIN
* Check the current account balance
* Deposit money into an account
* Withdraw money when sufficient funds are available
* View recent transaction history
* Change the account PIN
* Convert between supported currencies

## Technologies

* **C++**
* **Object-Oriented Programming**
* **File I/O**
* **Operator Overloading**

## Project Structure

The project is organized around C++ classes that handle card information, account operations, validation, transactions, and related functionality.

Transaction records are stored using a text file, allowing transaction history to persist between program runs.

## Project Purpose

This project was developed as a C++ practice project to apply object-oriented programming concepts to a practical application.

It provided experience with classes and objects, constructors, member functions, encapsulation, file I/O, operator overloading, input validation, and implementing application logic.
